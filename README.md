Airbnb Bangkok Market Analytics Dashboard

An interactive, 3-page Power BI dashboard that explores Bangkok's Airbnb market: price tiers, neighbourhood rankings, location and price patterns on a map, host performance and property types.

Project Overview

The goal was to turn raw Airbnb listing data into a dashboard that lets a user explore where bookings, prices and reviews are concentrated across Bangkok, and compare neighbourhoods, property types and hosts using filters.

Dashboard Pages
Page	What it shows
Overview	KPI cards (bookings, revenue, reviews, profit), top neighbourhoods by bookings, review comparison against last year, bookings by price tier
Locations	Map of listings, a neighbourhood table (average accommodates, average price, total reviews), and High Price Area / Top Reviewed Area / Top Profitable Area views
Performance	Top 5 hosts, total price by property type, occupancy and rating gauges

Interactive filters: Month, Property Type, Neighbourhood.

Key Insights (filtered to Entire condo listings)
879 bookings in the filtered view.
Mid-Range is the dominant price tier at 65.87% of bookings, followed by Budget (25.94%), Premium (7.51%) and Luxury (0.68%).
Vadhana has the most bookings, with Khlong Toei second.
Huai Khwang has the highest average price (THB 9,182), but Vadhana and Khlong Toei lead in total reviews (3,000+ each). Higher price does not mean more guest activity.

Figures above are for the Entire condo property-type filter. Other property types give different numbers.

Tools and Skills Used
Power BI for report design, interactivity and map visuals
DAX for KPI measures (bookings, revenue, profit, reviews and comparisons)
Geospatial visuals (map with location bubbles)
Data visualization (bar, line, donut, treemap, gauge and table visuals)
Data cleaning and preparation before reporting

What I Learned
Designing a multi-page dashboard with consistent navigation and filters.
Working with geospatial data and map visuals in Power BI.
Choosing the right visual for each question (ranking, share, trend, location).
Why validating every measure matters: a KPI that looks impressive can still be calculated wrongly.
